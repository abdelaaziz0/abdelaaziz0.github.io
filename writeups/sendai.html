01 - Environment & Scope

Environment & Scope

Sendai is a single Windows Domain Controller. No credentials are provided -the entire chain starts from unauthenticated access. Null SMB sessions are partially allowed and leak enough share content to build an initial user list without any credentials at all.

04 - Expired Passwords

Expired Passwords & Force-Change

nxc smb dc.sendai.vl -u users.txt -p '' --continue-on-success

[-] sendai.vl\elliot.yates:  STATUS_PASSWORD_MUST_CHANGE
[-] sendai.vl\thomas.powell: STATUS_PASSWORD_MUST_CHANGE
STATUS_PASSWORD_MUST_CHANGE - forcer le changement sans l'ancien mot de passe

STATUS_PASSWORD_MUST_CHANGE donne accès au flux de changement de mot de passe. changepasswd.py bascule en null session SAMR et pousse un nouveau mot de passe sans connaître l'ancien, ce que smbpasswd ne gère pas dans ce cas.

changepasswd.py sendai.vl/thomas.powell:@dc.sendai.vl -newpass 'P@ssw0rd123!'

[!] Password is expired or must be changed, trying to bind with a null session.
[*] Connecting to DCE/RPC as null session
[*] Password was changed successfully.
nxc smb dc.sendai.vl -u 'thomas.powell' -p 'P@ssw0rd123!'

[+] sendai.vl\thomas.powell:P@ssw0rd123!

08 - Post-User Recon

Credentials in Service Registry

Service ImagePath credentials

Les ACL par défaut permettent souvent aux utilisateurs authentifiés de lire HKLM\SYSTEM\CurrentControlSet\services. Ici, le service custom expose directement -u / -p dans son ImagePath.

dir -Path HKLM:\SYSTEM\CurrentControlSet\services |
  Get-ItemProperty | Select-Object ImagePath |
  select-string -NotMatch "svchost.exe" | select-string "exe"

# Extrait utile parmi la sortie complète :
@{ImagePath=C:\WINDOWS\helpdesk.exe -u clifford.davey -p [redacted] -k netsvcs}

Un service custom nommé helpdesk passe les credentials de clifford.davey directement sur sa ligne de commande. Ces credentials sont valides contre SMB :

nxc smb dc.sendai.vl -u 'clifford.davey' -p '[redacted]'

[+] sendai.vl\clifford.davey:[redacted]
09 - Privilege Escalation

AD CS ESC4 to Administrator

AD CS ESC4 - réécriture de template

ca-operators had Full Control on SendaiComputer. Rewriting the template with Certipy made it ESC1-like: requester-supplied SAN, Client Authentication EKU, and usable enrollment rights for clifford.davey.

clifford.davey can enroll with -upn administrator@sendai.vl.

The first certificate request failed with Object SID mismatch: the UPN said Administrator, but the request was still tied to clifford.davey. Supplying Administrator's SID with -sid fixed the mapping and kept the failed attempt explicit.

11 - Summary

Full Attack Chain

No credentials

Null SMB to username list

The sendai share is readable; transfer/ leaks users and RID brute completes the list.

Password state

Empty spray returns must-change

elliot.yates and thomas.powell return STATUS_PASSWORD_MUST_CHANGE.

Takeover

Force expired password change

changepasswd.py uses null SAMR and sets thomas.powell:P@ssw0rd123!.

Graph path

BloodHound + group self-add

thomas.powell adds himself to admsvc, which can read mgtsvc$'s managed password.

Credential material

gMSA dump

gMSADumper.py extracts the mgtsvc$ NT hash and Kerberos keys.

User shell

WinRM as mgtsvc$

mgtsvc$ is in Remote Management Users, so Pass-the-Hash reaches user.txt.

Post-user recon

Service registry credential

helpdesk.exe stores clifford.davey's cleartext password in ImagePath.

AD CS

ESC4 template rewrite

clifford.davey reaches ca-operators, rewrites SendaiComputer, then enrolls with Administrator SID.

Domain admin

Administrator hash and root flag

certipy auth yields Administrator NT hash; WinRM Pass-the-Hash reads root.txt.
